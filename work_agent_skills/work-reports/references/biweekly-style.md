# 双周报文体规范（依据部门实际提交稿）

参照件：`部门双周报_2026年第15期.docx`（机器人事业部，7.20–7.31）。
本文件描述**怎么写**，不描述写什么。

## 一、周期口径

本部门**只提交双周报**。日报是内部积累的素材，不对外提交；周报这一文种不存在，
不要生成、不要在目录或标题中出现"周报"。

## 二、层级与编号

固定四级，不自创层级：

```
机器人事业部
(7.20-7.31)

第一部分：上两周工作总结

一、智能机器人共性平台建设（一期）
（一）平台项目建设（一期）
1.场景训练平台
1.完成训练测试平台EPC工程竣工资料用印……
2.完成公共服务平台一期初步设计进度款支付流程提报。
```

- 一级：`一、` `二、`
- 二级：`（一）` `（二）`
- 三级：`1.场景训练平台`（小标题，不加句号）
- 条目：`1.` 起编，每条一句话，句末用句号

## 三、句式

**每条以动词开头，用完成态。**常用动词：完成、编制、协调、督促、梳理、推动、
修订、组织、提报、核验、摸排。

- 对：`完成设备采购项目安装调试款1348万元的支付。`
- 错：`我们通过多方协调的方式，顺利完成了设备采购项目的付款工作。`

**带日期、带对象、带金额。**具体数字是双周报的主要信息量。

- 对：`7月22日，与聆动通用座谈交流，围绕数据回购、数据运营公司出资事宜进行讨论。`
- 错：`近期与合作方就相关事宜进行了深入沟通。`

**结论用"一是……二是……"列举。**

- 对：`形成以下结论：一是聆动明确后续200万元出资相关事宜；二是聆动同意分五年期、总计不低于200万元。`

## 四、禁止

- 禁止形容词与程度副词：顺利、有序、扎实、深入、高效、积极、大力
- 禁止总结性套话：本期重点、工作亮点、取得显著成效、为下一步打下基础
- 禁止第一人称叙述过程："我们通过……方式""经过反复沟通后"
- 禁止把日报的过程性措辞直接搬进来；日报写"做了什么"，双周报写"完成了什么"
- 未确认的人名、机构名、金额不得写入；确有必要时标注待确认，不得猜测

## 五、自检

生成后逐条检查：

1. 是否动词开头、完成态？
2. 是否有具体日期或数字？没有的条目是否真的值得写？
3. 有没有出现禁用词？
4. 层级编号是否与参照件一致？
5. 是否出现了"周报"字样？
