# 法定公文文种与常用结构

《党政机关公文处理工作条例》列明十五种主要公文。先按行文目的和机关关系选文种，再组织内容。

| 文种 | 适用目的 | 常见正文组织 | 关键限制 |
|---|---|---|---|
| 决议 | 会议讨论通过重大决策事项 | 依据/会议情况、决议事项、执行要求 | 应有会议讨论通过依据 |
| 决定 | 对重要事项决策部署、奖惩、变更撤销事项 | 缘由、决定事项、执行要求 | 决策权限必须匹配 |
| 命令（令） | 公布规章、重大强制措施、衔级、嘉奖 | 发布依据、命令事项、施行要求 | 仅限有权机关或负责人 |
| 公报 | 公布重要决定或重大事项 | 背景、事实、决定或结果 | 面向社会正式公布 |
| 公告 | 向国内外宣布重要或法定事项 | 公告缘由、公告事项 | 适用范围较高，不代替一般通知 |
| 通告 | 在一定范围公布应遵守或周知事项 | 缘由、具体事项、实施要求 | 应明确适用范围 |
| 意见 | 对重要问题提出见解和处理办法 | 背景目标、原则、措施、保障 | 区分指导性与实施性意见 |
| 通知 | 发布、传达执行或周知事项，批转转发公文 | 缘由/依据、事项、执行要求 | 写清对象、动作、时限 |
| 通报 | 表彰、批评、传达精神或重要情况 | 基本事实、评价分析、要求 | 事实和评价须准确 |
| 报告 | 向上级汇报工作、反映情况、回复询问 | 基本情况、主要工作/问题、下一步安排 | 不得夹带请示事项 |
| 请示 | 向上级请求指示、批准 | 请示缘由、请示事项、结语 | 原则上一文一事、一个主送机关 |
| 批复 | 答复下级请示 | 引述请示、批复意见、执行要求 | 必须对应具体请示 |
| 议案 | 政府依法向同级人大或其常委会提请审议 | 案由、依据、议案内容、审议请求 | 主体和程序法定 |
| 函 | 不相隶属机关之间商洽、询答、请求批准或答复审批 | 缘由、事项、商请/答复语 | 注意平行行文语气 |
| 纪要 | 记载会议主要情况和议定事项 | 会议概况、议定事项、责任和落实要求 | 只写会议形成的情况与结论 |

## 容易误判的非公文材料

工作总结、工作方案、调研报告、汇报材料、领导讲话、简报、合同、制度、计划和会议记录通常是事务性文件材料，不因采用公文式字体和页边距就自动成为法定公文。

处理这些材料时：

1. 保留其真实材料名称和用途。
2. 应用公司标准文件格式。
3. 不添加未经要求的红头、文号、签发人、主送机关、版记或印章。

## 内容自检

- 文种是否与行文目的、职权和机关关系一致。
- 标题是否通常由发文机关、事由和文种构成，且简明准确。
- 主送机关是否确需办理或知晓。
- 数字、日期、单位名称、附件名称和正文引用是否一致。
- 层次序数是否依次为 `一、`、`（一）`、`1.`、`（1）`。
- 请示是否一文一事，报告是否未夹带请示。
- 措施是否有责任主体、适用范围和必要时限。
