# 官方依据与适用边界

检索日期：2026-07-24。

## 核心依据

1. 国家标准全文公开系统：GB/T 9704—2012《党政机关公文格式》
   - https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=F3CC9BEF482524C895FDA7A08BB4A70E
   - 状态：现行；2012-07-01实施；2025-05-30复审结论为继续有效。
   - 用途：公文纸张、版心、各要素编排、字体字号、页码及特殊格式。

2. 中国政府网：《党政机关公文处理工作条例》（中办发〔2012〕14号）
   - https://www.gov.cn/zhengce/2013-02/22/content_2640088.htm
   - 用途：十五种主要公文的定义、公文要素、行文规则、拟制办理与管理原则。

3. 教育部：《教育部公文处理规定》（教办〔2013〕7号）
   - https://www.moe.gov.cn/srcsite/A01/s7048/201309/t20130927_171853.html
   - 用途：官方机关实施示例；标题、正文、层次序数、附件说明、署名和日期等具体要求。

4. 国家发展改革委：《公文写作五步法》
   - https://www.ndrc.gov.cn/fggz/gbzj/wsgz/201508/t20150812_1105092.html
   - 用途：按行文目的、职权和机关关系选择法定文种，避免错用、滥用或生造文种。

## 官方实施例

- 吐鲁番市政府办公室《关于规范上报文字材料的通知》
  - https://www.tlf.gov.cn/tlfs/c108561/201804/c05e3f06a76642819e63c7d039d834c5.shtml
  - 支持标题 2 号小标宋、正文 3 号仿宋、一级黑体、二级楷体等常用纯文字材料层级。

- 财政部甘肃监管局《关于进一步规范公文处理工作的通知》
  - https://gs.mof.gov.cn/tongzhitonggao/201409/t20140909_1137075.htm
  - 支持层次序数、字体层级、阿拉伯数字成文日期及报告/请示等使用注意。

## 边界

- 国家标准规定版式，不替代具体机关的发文权限、签批流程、保密审查和印章管理。
- 地方或部门实施细则只能作为其适用范围内的补充，不得覆盖国家标准的通用要求。
- 公司内部纯文字格式可以借鉴公文字体体系，但不因外观相似而具有党政机关公文效力。
