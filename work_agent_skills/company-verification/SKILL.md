# 企业基础工商信息查询 Skill

## 一、启用条件

用户提出以下需求时启用：

- 查询企业成立时间、注册资本、法定代表人、注册地址、经营范围；
- 查询股东、持股比例、母公司、子公司、对外投资；
- 查询董事、监事、经理等主要人员；
- 判断两家公司属于母子公司、兄弟公司、参股关系还是业务合作关系；
- 梳理国企集团、平台公司、运营公司之间的股权和业务关系；
- 为可研报告、合作方案、尽调材料核验企业主体信息。

## 二、所需工具

| 工具 | 用途 |
|---|---|
| **edge-browser**（浏览器 MCP） | 打开天眼查搜索并获取完整工商页面 |
| **anysearch**（联网搜索） | 搜索关键词作为切入点，交叉验证 |
| 系统文件读写 | 保存查询结果 |

### 天眼查使用说明

天眼查（tianyancha.com）是本技能的首要数据源，理由：

- ✅ 搜索结果页可直接访问，无需登录即可查看基本信息、股东、对外投资
- ✅ 无验证码拦截（截止2026年7月）
- ✅ 搜索结果快照内容完整，公司名称、持股比例等关键字段均可见

### 不可用平台（不要尝试）

| 平台 | 原因 |
|---|---|
| **企知道（qizhidao.com）** | 滑动验证拦截，浏览器无法通过 |
| **爱企查（aiqicha.baidu.com）** | 百度安全验证拦截 |
| **其他需登录/验证码的工商平台** | 直接跳过 |

**规则**：任何时刻都优先打开天眼查，不要先试探企知道或爱企查。

## 三、核心原则

### 1. 先确认企业唯一身份

必须优先确认：

- 企业完整名称；
- 注册地；
- 统一社会信用代码（能查到时）；
- 成立时间。

存在同名或近似企业时，不得自行选定。

### 2. 股权关系必须双向核验

判断"A公司是否持有B公司"时，尽量同时查询：

- B公司的股东信息（在天眼查搜索结果中确认）
- A公司的对外投资列表

两侧信息一致，可信度更高。

### 3. 股权关系与业务关系分开

不得因以下情况直接认定母子公司关系：

- 法定代表人相同；
- 办公地址相同；
- 同属一个项目；
- 一方使用另一方设备；
- 一方受托运营另一方资产；
- 新闻中称"联合成立"但未披露持股关系。

### 4. 不把推算写成工商事实

只有公开页面明确显示持股比例时，才能写：

> A公司持有B公司70%股权。

如果只是根据注册资本、认缴金额或新闻内容推算，应写：

> 据现有公开信息推算，具体比例仍需以最新工商登记为准。

### 5. 所有结论注明查询时点

工商信息可能发生变更。正式输出应注明：

> 查询时间：YYYY年MM月DD日。

## 四、标准查询流程

### 第一步：anysearch 快速搜索（可选）

先用 anysearch 搜索目标企业全称，获取初步信息：

```text
"企业完整名称"
"企业完整名称" 天眼查
"企业完整名称" 股东
"企业完整名称" 对外投资
```

这一步不是必须的，但可以作为天眼查结果的交叉验证。如果 anysearch 返回了企知道等平台的摘要信息，只提取其中可读的内容（注册资本、成立日期、法定代表人），不要宣称访问了完整页面。

### 第二步：浏览器打开天眼查搜索

使用 edge-browser MCP 打开天眼查搜索页：

```
browser_navigate → https://www.tianyancha.com/search?key=企业全称
```

搜索 URL 格式固定为：
```
https://www.tianyancha.com/search?key={URL编码后的企业全称}
```

### 第三步：获取搜索结果快照

调用 `browser_snapshot` 获取页面可及性快照。

从快照中找到目标企业的卡片，提取以下字段：

1. **企业全称** — 搜索结果的标题链接
2. **登记状态** — 存续/注销/吊销
3. **法定代表人** — 名称和链接
4. **注册资本** — 含单位
5. **成立日期**
6. **统一社会信用代码**
7. **电话、邮箱、地址**
8. **标签** — 国有独资/国有控股/小微企业等

同时从快照中查看同一搜索结果页上列出的**对外投资企业卡片**，它们直接在搜索结果中呈现。识别方式：

- 每张企业卡片都有自身的企业名称、注册资本、成立日期、法定代表人
- 卡片下方显示"股东：XXX"表明其股东信息
- 如果股东显示为"合肥国先控股有限公司"，即可确认这是被投资企业

**注意**：天眼查搜索结果页面可能列出多页结果，但目标企业的对外投资企业通常出现在同一搜索页面中（天眼查会智能返回关联企业）。如果对外投资企业不在第一页，可以分别搜索各子公司的全称。

### 第四步：点击进入企业详情页（如需更多信息）

如果搜索结果页面提供的信息已经足够（股权结构、对外投资、主要人员均已覆盖），可以不点击进入详情页。

如需查看股东详细信息、股权穿透、历史变更等，可以点击企业名称链接进入详情页，然后再次 snapshot。

### 第五步：查询次级子公司

对于控股子公司（持股>50%），应进一步查询其对外投资情况。

用同样方法搜索该子公司全称，查看其是否也有对外投资。

### 第六步：交叉验证

使用 anysearch 补充搜索以下来源，交叉核验：

```text
"企业全称" 招聘公告
"企业全称" 官网
"企业全称" 政府
"企业全称" 成立
"企业全称" 项目
```

正式材料主要用于核验：

- 上级股东；
- 国企层级；
- 公司定位；
- 公司与项目的关系；
- 是否为全资、控股或参股公司。

## 五、信息可信度分级

### A级：天眼查公开搜索结果页

天眼查搜索结果页面显示的企业基本信息、股东、对外投资信息。可直接使用。

### B级：政府、国企或企业正式材料

包括政府网站、国企官网、企业官网、招聘公告、招投标文件和正式新闻稿。

可表述为：据公司公开材料……/据政府公开信息……/据招聘公告……

### C级：权威媒体引用工商平台

例如媒体明确写明"天眼查APP显示……"。可用于核验成立时间、注册资本、法定代表人、经营范围及股东名称。精确股权比例最好再找其他来源交叉确认。

### D级：搜索摘要和一般转载

只能作为线索。不得单独用于确认复杂股权关系、实际控制人或最新高管名单。

## 六、输出格式

### 1. 单家公司查询

```markdown
## 企业基本信息

- 企业全称：
- 统一社会信用代码：
- 成立日期：
- 注册资本：
- 法定代表人：
- 企业类型：
- 登记状态：
- 注册地址：
- 经营范围：
- 查询时间：

## 股东及股权结构

| 股东 | 持股比例 | 认缴金额 | 核验来源 |
|---|---:|---:|---|

## 主要人员

| 姓名 | 职务 | 核验来源 |
|---|---|---|

## 对外投资及分支机构

| 企业名称 | 关系 | 持股比例 | 状态 |
|---|---|---:|---|

## 核验结论

用2—4句话说明：
1. 控股股东是谁；
2. 是否存在子公司；
3. 与相关企业是什么关系；
4. 哪些信息仍需进一步核验。
```

### 2. 多家公司关系查询

```markdown
## 股权关系图

集团或母公司
├── 公司A（持股比例）
├── 公司B（持股比例）
└── 公司C（持股比例）

## 关系说明

- 公司A与公司B：
- 公司A与公司C：
- 公司B与公司C：
- 资产持有主体：
- 业务运营主体：
```

## 七、常见踩坑点（避坑指南）

| 坑 | 正确做法 |
|---|---|
| 企知道页面有验证码，依然去试 | **永远优先开天眼查** |
| 爱企查有百度验证，依然去试 | 同上 |
| 天眼查搜索后只拿了摘要就退出了 | 必须 snapshot 快照，逐字段提取 |
| 对外投资列表的企业名称被截断没注意 | 通过浏览器快照看完整名称 |
| 搜到一次就报全了，不做交叉验证 | 至少用 anysearch 补一个来源核验 |
| 把"法定代表人相同"直接写"母子公司" | 必须确认股权登记 |
| 没写查询日期 | 所有结论必须标注查询时点 |
| 天眼查搜索后没看"股东"字段下的被投资企业卡片 | 搜索结果页直接包含关联企业卡片，一并提取 |
| 注册资本单位不一致时直接抄 | 统一写"万人民币" |
| 持股比例来源只有新闻报道 | 标注"C级"，提醒进一步核验 |
| 天眼查打不开就放弃 | 换 anysearch 搜索关键词，用政府/国企公告交叉验证 |

## 八、最终质量检查

提交结果前逐项检查：

- [ ] 企业名称是否完整准确；
- [ ] 是否区分公司、项目和业务平台；
- [ ] 是否区分法定代表人与法人；
- [ ] 股权比例是否有直接来源；
- [ ] 是否反向查询了母公司对外投资；
- [ ] 是否区分子公司、参股公司、兄弟公司和运营方；
- [ ] 是否将业务合作误写为股权关系；
- [ ] 是否注明查询日期；
- [ ] 是否标明未核实或存在冲突的信息；
- [ ] 是否优先使用天眼查而不是验证码平台。

## 九、执行底线

1. 查不到就写"暂未查到"，不得猜测；
2. 搜索摘要只能作为线索，不能伪装成完整工商档案；
3. 工商平台可能有更新延迟，重要结论必须交叉验证；
4. 精确股权和控制关系存在冲突时，不得自行选择；
5. 天眼查无法访问时，用政府/国企公告替代，不要重复尝试被拦截的平台；
6. 用户需要正式上会或签约时，应提示以最新营业执照、公司章程、股东名册或企业内部股权材料为最终依据。
