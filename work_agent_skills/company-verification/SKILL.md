# 企业基础工商信息查询 Skill

## 一、启用条件

用户提出以下需求时启用：

- 查询企业成立时间、注册资本、法定代表人、注册地址、经营范围；
- 查询股东、持股比例、母公司、子公司、对外投资；
- 查询董事、监事、经理等主要人员；
- 判断两家公司属于母子公司、兄弟公司、参股关系还是业务合作关系；
- 梳理国企集团、平台公司、运营公司之间的股权和业务关系；
- 为可研报告、合作方案、尽调材料核验企业主体信息。

## 二、所需工具

| 工具 | 用途 |
|---|---|
| **edge-browser**（浏览器 MCP） | 打开用户提供的企业详情链接或企业信息平台页面，读取当前可见字段 |
| **anysearch**（联网搜索） | 搜索关键词作为切入点，交叉验证公开来源 |
| 系统文件读写 | 保存查询结果 |

### 来源选择原则

天眼查（tianyancha.com）是默认优先来源之一，但不是唯一来源。企查查、爱企查、国家企业信用信息公示系统、政府/国企官网、企业官网、招投标公告和招聘公告均可作为补充或交叉验证来源。

- 用户在消息中提供的 URL 具有最高取证优先级：必须先打开并检查页面标题、企业名称、统一社会信用代码及目标字段。
- 不能因为过去遇到验证码、登录墙或页面变化，就预先判定某个平台当前不可用。
- 只有实际打开页面后确认被验证码、登录、空白页或权限限制阻断，才能标记该来源当前不可访问，并切换其他来源。
- 不得把搜索结果页、企业详情页上的平台客服电话误认成目标企业登记电话。

### 受限平台处理

企查查、爱企查、企知道及其他企业信息平台的可访问性会随登录态、页面版本和反爬策略变化。不要把它们写死为“不可用”，也不要仅凭历史经验跳过用户明确提供的页面。实际访问受阻时，记录“该来源当前不可访问”，继续使用其他可读来源。

## 三、核心原则

### 1. 先确认企业唯一身份

必须优先确认：

- 企业完整名称；
- 注册地；
- 统一社会信用代码（能查到时）；
- 成立时间。

存在同名或近似企业时，不得自行选定。

### 2. 股权关系必须双向核验

判断"A公司是否持有B公司"时，尽量同时查询：

- B公司的股东信息（在天眼查搜索结果中确认）
- A公司的对外投资列表

两侧信息一致，可信度更高。

### 3. 股权关系与业务关系分开

不得因以下情况直接认定母子公司关系：

- 法定代表人相同；
- 办公地址相同；
- 同属一个项目；
- 一方使用另一方设备；
- 一方受托运营另一方资产；
- 新闻中称"联合成立"但未披露持股关系。

### 4. 不把推算写成工商事实

只有公开页面明确显示持股比例时，才能写：

> A公司持有B公司70%股权。

如果只是根据注册资本、认缴金额或新闻内容推算，应写：

> 据现有公开信息推算，具体比例仍需以最新工商登记为准。

### 5. 所有结论注明查询时点

工商信息可能发生变更。正式输出应注明：

> 查询时间：YYYY年MM月DD日。

## 四、标准查询流程

### 第一步：先检查用户提供的链接（如有）

如果用户提供了企查查、爱企查、天眼查或其他企业详情 URL：

1. 直接打开每个用户提供的 URL；
2. 从页面标题、企业全称、统一社会信用代码、注册地址和成立日期确认是否为同一主体；
3. 读取用户要求的字段，尤其是页面明确标注的“电话/联系电话”；
4. 记录每个字段的来源 URL、页面状态和查询时间；
5. 如果某个页面打不开，说明具体阻断原因，再继续检查其他用户提供的链接。

### 第二步：确认企业唯一身份

必须优先确认：

- 企业完整名称；
- 注册地；
- 统一社会信用代码（能查到时）；
- 成立时间。

如果用户只提供简称，先用搜索和企业详情页确认正式主体；存在同名或近似企业时，不得自行选定。

### 第三步：anysearch 快速搜索（可选）

在检查用户链接后，可用 anysearch 搜索目标企业全称，获取补充信息：

```text
"企业完整名称"
"企业完整名称" 天眼查
"企业完整名称" 股东
"企业完整名称" 对外投资
```

这一步不是必须的，也不能替代用户提供的企业详情页。搜索摘要只能作为线索；如果搜索结果指向企查查、爱企查等页面，应在页面实际可访问时打开并核对，不得只凭摘要声称已核实完整工商信息。

### 第四步：浏览器打开企业信息页面

默认可打开天眼查搜索页：

```
browser_navigate → https://www.tianyancha.com/search?key=企业全称
```

搜索 URL 格式固定为：
```
https://www.tianyancha.com/search?key={URL编码后的企业全称}
```

如果天眼查关键字段被遮蔽、页面动态加载失败或当前访问受限，应检查其他可访问的企业详情页（包括用户提供的企查查、爱企查链接），不得直接将脱敏结果写成“公开网页没有完整信息”。

### 第五步：获取企业详情快照

调用 `browser_snapshot` 获取页面可及性快照。

从快照中找到目标企业的卡片，提取以下字段：

1. **企业全称** — 搜索结果的标题链接
2. **登记状态** — 存续/注销/吊销
3. **法定代表人** — 名称和链接
4. **注册资本** — 含单位
5. **成立日期**
6. **统一社会信用代码**
7. **电话、邮箱、地址**
8. **标签** — 国有独资/国有控股/小微企业等

同时从快照中查看同一搜索结果页上列出的**对外投资企业卡片**，它们直接在搜索结果中呈现。识别方式：

- 每张企业卡片都有自身的企业名称、注册资本、成立日期、法定代表人
- 卡片下方显示"股东：XXX"表明其股东信息
- 如果股东显示为"合肥国先控股有限公司"，即可确认这是被投资企业

**注意**：天眼查搜索结果页面可能列出多页结果，但目标企业的对外投资企业通常出现在同一搜索页面中（天眼查会智能返回关联企业）。如果对外投资企业不在第一页，可以分别搜索各子公司的全称。

### 第六步：点击进入企业详情页（如需更多信息）

如果搜索结果页面提供的信息已经足够（股权结构、对外投资、主要人员均已覆盖），可以不点击进入详情页。

如需查看股东详细信息、股权穿透、历史变更等，可以点击企业名称链接进入详情页，然后再次 snapshot。

### 第七步：查询次级子公司

对于控股子公司（持股>50%），应进一步查询其对外投资情况。

用同样方法搜索该子公司全称，查看其是否也有对外投资。

### 第八步：交叉验证

使用 anysearch 补充搜索以下来源，交叉核验：

```text
"企业全称" 招聘公告
"企业全称" 官网
"企业全称" 政府
"企业全称" 成立
"企业全称" 项目
```

正式材料和企业详情页主要用于核验：

- 上级股东；
- 国企层级；
- 公司定位；
- 公司与项目的关系；
- 是否为全资、控股或参股公司。

对联系电话等单字段，若两个页面的企业名称和统一社会信用代码一致，即使一个页面显示完整号码、另一个页面只显示部分号码，也可以报告完整号码，并注明完整号码来源；不得因为天眼查一侧脱敏就否定另一侧的完整字段。

## 五、信息可信度分级

### A级：企业详情页明确字段或官方登记来源

企查查、爱企查、天眼查等企业详情页中明确标注且与目标主体唯一匹配的字段，可用于该字段核验。国家企业信用信息公示系统、政府/国企官网和企业官网的直接信息同属高可信来源。

### B级：政府、国企或企业正式材料

包括政府网站、国企官网、企业官网、招聘公告、招投标文件和正式新闻稿。

可表述为：据公司公开材料……/据政府公开信息……/据招聘公告……

### C级：权威媒体引用工商平台

例如媒体明确写明"天眼查APP显示……"。可用于核验成立时间、注册资本、法定代表人、经营范围及股东名称。精确股权比例最好再找其他来源交叉确认。

### D级：搜索摘要和一般转载

只能作为线索。不得单独用于确认复杂股权关系、实际控制人或最新高管名单。

## 六、输出格式

### 1. 单家公司查询

```markdown
## 企业基本信息

- 企业全称：
- 统一社会信用代码：
- 成立日期：
- 注册资本：
- 法定代表人：
- 企业类型：
- 登记状态：
- 注册地址：
- 经营范围：
- 查询时间：

## 股东及股权结构

| 股东 | 持股比例 | 认缴金额 | 核验来源 |
|---|---:|---:|---|

## 主要人员

| 姓名 | 职务 | 核验来源 |
|---|---|---|

## 对外投资及分支机构

| 企业名称 | 关系 | 持股比例 | 状态 |
|---|---|---:|---|

## 核验结论

用2—4句话说明：
1. 控股股东是谁；
2. 是否存在子公司；
3. 与相关企业是什么关系；
4. 哪些信息仍需进一步核验。
```

### 2. 多家公司关系查询

```markdown
## 股权关系图

集团或母公司
├── 公司A（持股比例）
├── 公司B（持股比例）
└── 公司C（持股比例）

## 关系说明

- 公司A与公司B：
- 公司A与公司C：
- 公司B与公司C：
- 资产持有主体：
- 业务运营主体：
```

## 七、常见踩坑点（避坑指南）

| 坑 | 正确做法 |
|---|---|
| 过去某个平台有验证码，直接认定当前也不可用 | 先实际打开；只有当前确实受阻才切换来源 |
| 用户已经提供企业详情 URL，却只查默认平台 | 先检查用户提供的 URL，并核对统一社会信用代码 |
| 天眼查搜索后只拿了摘要就退出了 | 必须 snapshot 快照，逐字段提取 |
| 对外投资列表的企业名称被截断没注意 | 通过浏览器快照看完整名称 |
| 搜到一次就报全了，不做交叉验证 | 至少用 anysearch 补一个来源核验 |
| 把"法定代表人相同"直接写"母子公司" | 必须确认股权登记 |
| 没写查询日期 | 所有结论必须标注查询时点 |
| 天眼查搜索后没看"股东"字段下的被投资企业卡片 | 搜索结果页直接包含关联企业卡片，一并提取 |
| 注册资本单位不一致时直接抄 | 统一写"万人民币" |
| 持股比例来源只有新闻报道 | 标注"C级"，提醒进一步核验 |
| 一个来源电话被遮蔽就认定没有完整电话 | 检查其他可访问企业详情页并按统一社会信用代码交叉核验 |
| 把平台客服电话当成企业电话 | 只采集目标企业详情区明确标注的电话字段 |
| 天眼查打不开就放弃 | 记录阻断原因，换其他可访问企业详情页或政府/国企公告交叉验证 |

## 八、最终质量检查

提交结果前逐项检查：

- [ ] 企业名称是否完整准确；
- [ ] 是否区分公司、项目和业务平台；
- [ ] 是否区分法定代表人与法人；
- [ ] 股权比例是否有直接来源；
- [ ] 是否反向查询了母公司对外投资；
- [ ] 是否区分子公司、参股公司、兄弟公司和运营方；
- [ ] 是否将业务合作误写为股权关系；
- [ ] 是否注明查询日期；
- [ ] 是否标明未核实或存在冲突的信息；
- [ ] 是否检查了用户提供的全部企业详情链接；
- [ ] 每个联系电话是否有明确的企业字段来源；
- [ ] 是否区分了企业登记电话、企业公开联系电话和平台客服电话。

## 九、执行底线

1. 只有在检查用户提供的链接、当前可访问的企业详情页和必要的补充搜索后仍无结果，才能写“暂未查到”，不得猜测；
2. 搜索摘要只能作为线索，不能伪装成完整工商档案；
3. 工商平台可能有更新延迟，重要结论必须交叉验证；
4. 精确股权和控制关系存在冲突时，不得自行选择；
5. 任一平台当前无法访问时，记录实际阻断原因并使用其他可访问来源，不得引用过时的“平台固定不可用”规则；
6. 用户需要正式上会或签约时，应提示以最新营业执照、公司章程、股东名册或企业内部股权材料为最终依据。
