# 微信公众号文章搜索

## 工具

通过 `mcporter` 或 `sys_skill` 调用已挂载的微信搜索 MCP 工具：

- `weixin_search`：按关键词搜索文章；
- `weixin_search_all`：在用户明确要求时翻页搜索；
- `resolve_weixin_article_url`：按需把一条搜狗跳转链接解析为微信原文链接；
- `get_weixin_article_content`：读取指定文章正文。

## 查询流程

1. 先提炼 1—3 个高价值关键词，并优先执行小范围搜索；
2. 默认每个关键词搜索 1—3 页，只有用户明确要求时才扩大范围；
3. 对候选文章按标题、公众号、发布时间和摘要去重、筛选；搜索工具会把原始时间戳转换为北京时间；
4. 只对相关性最高的少量文章调用 `resolve_weixin_article_url`，再读取正文；不要为全部搜索结果批量解析真实链接；
5. 用户提供微信文章链接时，优先直接读取该链接，不要重新猜测文章地址；
6. 同时使用公开网页搜索或 `site:mp.weixin.qq.com` 结果补充，不把搜狗微信作为唯一来源。

## 稳定性与合规

- 控制请求频率，避免批量关键词和深分页；
- 遇到验证码、登录墙或服务不可用时，记录实际阻断原因并切换公开网页搜索或用户提供的链接；
- 不绕过验证码、不伪造浏览器行为、不把搜狗或 MCP 平台客服电话当作文章来源；
- 不能读取正文时，明确区分“搜索结果摘要”和“文章全文”，不得把摘要写成全文事实。

## 输出字段

整理文章时优先保留：标题、公众号、发布时间、微信原文链接、搜索关键词、正文/摘要、涉及组织、服务类别、运营模式和来源状态。
